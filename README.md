# CreateForm
Apps Scripts per Google Sheet per creare Google Form

Nella colonna A prende la domanda, nelle colonne BCDE le possibili risposte.

Aggiunta opzione per creare Google Doc ed evidenziare risposta giusta.
Nella colonna F trova la lettera della risposta giusta {B,C,D,E} da evidenziare

Chiama il form/doc con stesso nome del Sheet e lo mette nella stessa posizione.
